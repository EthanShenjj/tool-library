# 图章 · 批量水印

面向电商商品图的离线批量水印编辑器。图片只在浏览器内存中处理，不会上传到服务器。

## 构建

在仓库根目录执行：

```bash
npm run build:watermark
```

构建会把 CSS、JavaScript 和 JSZip 全部内嵌，生成：

- `image-watermark/src/index.html`：可直接双击预览的自包含开发入口；源模板保存在同目录的 `template.html`。
- `image-watermark/dist/image-watermark.html`：独立交付文件。
- `public/downloads/image-watermark.html`：团队工具台的在线版与下载源。

## 使用限制

- 最多同时导入 20 张图片，总大小不超过 100 MB。
- 支持 JPG、PNG、WebP；WebP 输出为 PNG。
- 单张图片宽 × 高不超过 4000 万像素（约 40 MP），超出请先缩小再导入；Logo 图片同限。
- 水印支持单个、整齐平铺、错位多排和随机散布（每张图片的散布图案相互独立），可调旋转角度，并明确设置每张图片的水印数量（4–40 个）。
- 导出时统一快照当前水印设置，导出过程中清单不可增删；文字与 Logo 均未启用时无法导出。
- 清单支持逐张勾选、全选、导出选中和全部导出；多张图片导出为 ZIP（图片本身已是压缩格式，ZIP 不做二次压缩），单张图片直接保存。
- 预览支持上一张/下一张切换、键盘方向键、按钮缩放、触控板捏合缩放、适应窗口和 1:1 原图大小。预览缩放不会改变导出尺寸。
- HarmonyOS 设备应优先使用工具台中的 HTTPS 在线版；本地 HTML 与 ZIP 下载能力需按具体设备和浏览器验证。
