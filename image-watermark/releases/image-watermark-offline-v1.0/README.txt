图章 · 商品图批量水印 v1.0

一、使用方式
1. 解压离线包。
2. 双击“图章-批量水印.html”。
3. 使用 Chrome、Edge、Safari 等现代浏览器打开。
4. 添加商品图片，设置文字或 Logo 水印，然后导出。

二、支持功能
- 一次导入最多 20 张图片，总大小不超过 100 MB。
- 支持 JPG、PNG、WebP。
- 支持文字水印和透明 Logo 水印。
- 支持单个、平铺、错位、随机排列。
- 支持数量、位置、角度、字号、颜色和透明度设置。
- 支持勾选导出、全部导出和逐张保存。
- 多张图片自动打包为 ZIP。
- 支持上一张/下一张、缩放、适应窗口和 1:1 查看。

三、隐私说明
图片只在当前浏览器和设备内处理，不会上传到服务器。关闭页面后，本次导入内容会被释放。

四、设备说明
- Windows、Mac：推荐使用最新版 Chrome 或 Edge，Mac 也可使用 Safari。
- 鸿蒙设备：本地 HTML 的选图和下载能力取决于具体设备与浏览器；如果无法保存 ZIP，请使用在线版或逐张保存。

五、注意事项
- WebP 输入图片导出为 PNG。
- 导出过程中请保持页面开启。
- 大批量、高分辨率图片会占用较多内存，建议关闭其他大型应用。
- 本工具聚焦批量加水印，不包含裁剪、调色等完整修图功能。
