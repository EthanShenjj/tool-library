# 每周工作回顾

当用户需要整理一周工作或进行复盘时，使用这个 Skill。

## 输入

本周的工作笔记、已完成事项和未完成任务。

## 步骤

1. 梳理本周完成的关键事项，按项目分组。
2. 提取遇到的问题、采取的行动和获得的经验。
3. 列出需要跟进的事项和下周最重要的三件事。
4. 用简洁中文输出周回顾，事实不明确时标注待确认。

## 输出

- 本周成果
- 问题与经验
- 待跟进事项
- 下周重点
