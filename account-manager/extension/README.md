# 账号管理 · Chrome 快速保存插件

1. 下载 ZIP 并解压，保留包含 manifest.json 的文件夹。
2. 在 Chrome 打开 chrome://extensions，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
4. 点击 Chrome 工具栏的拼图图标，将“账号管理 · 快速保存”固定到工具栏。
5. 在同一 Chrome 中打开 https://team-toolbox.vercel.app/tools/account-manager 并完成登录。
6. 浏览任意 HTTP/HTTPS 网页时点击插件。平台默认取域名，网址自动带入；账号、密码与备注均可留空。

保存到固定的团队工具台地址。插件会复用或打开一个后台工具台标签页，请保留该标签页以便后续快速保存；不需要填写访问密钥。

同域名（忽略开头的 www.）和同账号会提醒重复；其他子域名分开判断。可以选择更新已有记录或另存一条。更新时，空密码和空备注保留原内容；需要清除原内容时，请在工具台编辑。

密码只保留在本次弹窗及保存请求的内存中，不写入本地或同步存储，不采集网站表单中的账号密码。关闭弹窗后未提交的输入不会保存。登录过期时，请前往工具台登录后重新打开插件。

开发：在仓库根目录执行 npm run build:extension，会生成 public/downloads/account-manager-chrome-extension.zip 和 .vercel/account-manager-extension/（可直接加载此目录）。

交互：保存按钮固定在弹窗底部，备注按需展开。支持 Ctrl / ⌘ + Enter 保存；出现重复记录时仍需明确点击更新或另存。修改密码、备注和平台名称会保留已选的重复记录，修改网址或账号会重新查重。网址修改后可点击“恢复当前网页”。保存成功后可前往工具台查看，或点击“再存一个账号”清空账号、密码和备注并保留平台与网址。

更新插件：重新下载并解压 ZIP，在 chrome://extensions 中重新加载原扩展（将原目录文件替换为新文件后点击刷新），或移除旧版再加载新文件夹。

1.2.0 新增 URL 平台识别：自动建议平台名称并显示用途分类，例如 GitHub / 开发工具、小红书 / 社交内容。未知域名显示为“未分类”，仍可手动填写平台名称并保存。识别在本地通过域名规则完成，不访问目标网页，不跟随短链接，不向外部识别服务发送网址。

网页账号列表支持按用途分类筛选和搜索，已有记录也会根据 URL 显示分类，手动填写的平台名称保持原样。分类由 URL 实时计算，无需数据库迁移。识别规则统一维护在 lib/account-platform.ts，构建时编译入插件的 platforms.js。
